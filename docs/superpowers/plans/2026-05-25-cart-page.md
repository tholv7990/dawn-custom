# P4b Cart Page — Minimals Skin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Skin Dawn's native cart into the Minimals 2-col cart (items + sticky summary) + trust/payment block, with zero `cart.js`/checkout edits.

**Architecture:** `assets/section-ct-cart.css` skins both cart sections and creates the 2-col via `#MainContent:has(cart-items)` grid (fail-open to stacked). `main-cart-footer.liquid` gets one additive trust-row+payment-badges block (reusing `.ct-trust-chip`). No logic touched.

**Tech Stack:** Liquid, plain CSS, `--ct-*` tokens. Spec: `docs/superpowers/specs/2026-05-25-cart-page-design.md`.

**Branch:** `feat/minimals-foundation`. **Verification:** `shopify theme check` stays **14**; live `theme dev` is the user's gate.
