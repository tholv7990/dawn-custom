## Task 1: Footer skin CSS + load

**Files:** Create `assets/section-ct-footer.css`; modify `sections/footer.liquid`.

- [ ] **Step 1: Create `assets/section-ct-footer.css`.**

```css
/* section-ct-footer.css — Minimals dark footer skin over Dawn's native footer.
   Flips the footer dark by overriding the color-scheme vars on .footer (reuses
   Dawn's --color-* plumbing), then tweaks headings/links/newsletter/social.
   Payment icons stay Dawn-native (payment_type_svg_tag full-color). Presentation
   only; newsletter form, social-icons, localization, policies untouched. */

/* ---- Flip dark (element+class beats .color-scheme-N) ---- */
footer.footer {
  --color-background: 33, 43, 54;   /* #212B36 */
  --color-foreground: 255, 255, 255;
  background-color: rgb(var(--color-background));
  color: rgba(255, 255, 255, 0.66);
  margin-top: 0;
}
footer.footer.gradient { background: rgb(var(--color-background)); }

/* ---- Column headings (mono, uppercase) ---- */
.footer-block__heading {
  font-family: var(--ct-font-mono);
  font-size: var(--ct-text-xs);
  font-weight: 500;
  letter-spacing: 0.12em;
  text-transform: uppercase;
  color: #fff;
}

/* ---- Brand block ---- */
.footer-block__brand-info .rte { color: rgba(255, 255, 255, 0.5); font-size: var(--ct-text-sm); }

/* ---- Link lists ---- */
.footer-block__details-content .list-menu__item--link,
.footer-block__details-content a {
  color: rgba(255, 255, 255, 0.55);
  font-size: var(--ct-text-sm);
}
.footer-block__details-content .list-menu__item--link:hover,
.footer-block__details-content a:hover { color: #fff; }

/* ---- Newsletter form (dark) ---- */
.footer-block__newsletter .field {
  border: 1px solid rgba(255, 255, 255, 0.18);
  border-radius: var(--ct-r-md);
  background: rgba(255, 255, 255, 0.04);
  overflow: hidden;
}
.footer-block__newsletter .field__input { background: transparent; border: 0; color: #fff; box-shadow: none; }
.footer-block__newsletter .field__input::placeholder { color: rgba(255, 255, 255, 0.4); }
.footer-block__newsletter .field__label { color: rgba(255, 255, 255, 0.4); }
.footer-block__newsletter .newsletter-form__button { color: #fff; }
.footer-block__newsletter .newsletter-form__button:hover { color: var(--ct-accent); }
.footer-block__newsletter .newsletter-form__message { color: rgba(255, 255, 255, 0.8); }

/* ---- Social icons ---- */
.footer__list-social .list-social__link { color: rgba(255, 255, 255, 0.7); }
.footer__list-social .list-social__link:hover { color: #fff; }

/* ---- Bottom bar ---- */
.footer__content-bottom { border-top: 1px solid rgba(255, 255, 255, 0.1); margin-top: var(--ct-space-5); }
.footer__content-bottom-wrapper { padding-top: var(--ct-space-4); }
.footer__copyright,
.copyright__content { color: rgba(255, 255, 255, 0.4); font-size: var(--ct-text-xs); }
.footer__copyright a,
.policies a { color: rgba(255, 255, 255, 0.4); }
.footer__copyright a:hover,
.policies a:hover { color: #fff; }

/* ---- Localization selectors (dark-friendly) ---- */
.footer__localization .localization-form__select,
.footer__localization .disclosure__button { color: rgba(255, 255, 255, 0.7); border-color: rgba(255, 255, 255, 0.18); }
.footer__localization .caption-large { color: rgba(255, 255, 255, 0.5); }

/* ---- Payment icons: keep Dawn native full-color; spacing only ---- */
.footer__payment { margin-top: var(--ct-space-2); }
```
